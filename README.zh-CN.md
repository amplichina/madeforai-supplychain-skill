# MadeForAI 官方供应链连接器

这是 MadeForAI 的开源 MCP 连接器。它负责把 Codex、Claude、Gemini 等 AI 客户端的制造任务安全发送到 MadeForAI 官方云端。

## 公开与私有边界

公开连接器只包含：

- MCP stdio 接入；
- 用户侧工具；
- 到 `https://api.madeforai.net/mcp` 的安全转发；
- 订单状态和生产反馈查询。

它不包含：

- 订单数据库；
- 中文生产后台；
- 供应商资料与生产知识资产；
- 生产端账号；
- 付款确认权限；
- 质检、物流和完成交付权限。

真实订单只有连接 MadeForAI 正式域名并通过官方身份验证后，才会进入 MadeForAI 生产后台。修改后的第三方分支不代表 MadeForAI，也无法取得 MadeForAI 的订单、数据库、生产账号或供应商资料。

## 安全边界

当前版本不生成图片、不运行大模型、不处理真实付款，也不会自动向工厂下单。价格必须来自人工生产反馈，所有不可逆步骤继续由人工确认。
