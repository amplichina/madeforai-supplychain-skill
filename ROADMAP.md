# Roadmap

## Current

- Official stdio connector for Codex, Claude, Gemini, Cursor, and other MCP clients.
- Fixed routing to the MadeForAI hosted control plane.
- Nine public user-side tools.
- Human-approved order and quote workflow.
- Invited-client access tokens.

## Next

- Replace invited bearer tokens with standards-based OAuth when client support and onboarding requirements are stable.
- Add signed official package distribution and automated release provenance.
- Improve international onboarding and localized AI guidance.

The public connector will not add a task database, supplier marketplace, operator workspace, payment confirmation, or fulfillment administration. Those remain part of the MadeForAI hosted service.
