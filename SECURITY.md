# Security

## Credential handling

Use only `MADEFORAI_ACCESS_TOKEN` to authenticate the official connector. Never commit this value or include it in screenshots, logs, issues, or examples.

The connector intentionally fixes its upstream endpoint to `https://api.madeforai.net/mcp`. Environment variables cannot redirect the official package to another fulfillment service.

## Reporting

Report security issues privately to the MadeForAI maintainers. Do not include access tokens, customer task data, supplier data, or personal information in a public issue.
